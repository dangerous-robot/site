# v1.0.0 Roadmap

**Status**: In progress, active release line (betas toward 1.0.0)  
**Last updated**: 2026-10-08  
**Working version**: `1.0.0-beta.6` (per `VERSION.md`)

This release line carries the refocus: the site's focus shifts to AI literacy, advocacy, and writing that helps people avoid AI or use it wisely. The research archive (claims, sources, criteria) stays as a cornerstone rather than the backbone. Each beta is a deployed release; the beta label is dropped at 1.0.0.

**Work items** have IDs like `SITE-J`: a topic prefix (`SITE` reader-facing pages, `RE` research archive and pipeline, `SEC` security, `OPS` repo, agent and deploy tooling) and a letter. Letters run A, B, C … Z, then AA, AB … across this roadmap, so the letter alone is unique. IDs are permanent: never changed or reused. Cite an item as "SITE-J (Responsible AI chatbots)", not the bare ID. Every work item is Scheduled work (`AGENTS.md` § Release planning); register code for one with `python3 scripts/release-gate/work_item.py start --release v1.0.0 --section "SITE-J (Responsible AI chatbots)"`, or `--plan <path>` when it has a plan.

Status key: `done` | `in progress` | `ready` (plan exists, not started) | `plan needed` | `decision needed` | `deferred` (set aside; plan in `plans/deferred/`, tracked in `UNSCHEDULED.md`)
